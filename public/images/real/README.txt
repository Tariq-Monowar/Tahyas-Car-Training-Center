REAL PHOTOS — আসল ছবি এখানে রাখুন
===================================

The .webp files already here are illustrative lesson scenes (see public/images/CREDITS.md).
They match each course. They are NOT this centre's cars, trainers, or students.
Replace a file by saving YOUR photo with the same name (.jpg, .jpeg, .png or .webp).
এখানকার ছবি প্রতীকী। নিজের ছবি একই নামে রাখলে সেটাই দেখাবে।

  hero.jpg            → Top of the page (best: a learner driving with the trainer, landscape)
  center-front.jpg    → Front of the training centre (shown next to the map)
  women.jpg           → Women's training section (with permission only)
  course-basic.jpg    → Basic Driving course card
  course-advance.jpg  → Advanced Driving course card
  course-parking.jpg  → Reverse Parking course card
  course-highway.jpg  → Highway Driving course card
  course-women.jpg    → Women's Training course card
  trainer-1.jpg …     → Trainer photos (also add the trainer in src/config/site.ts → trainers)

  gallery/            → ANY number of photos; all appear in the gallery, sorted by file name
                        (01.jpg, 02.jpg …). Captions: src/config/site.ts → galleryCaptions

Tips: landscape photos, at least 1600px wide, faces not at the very edge.
No need to resize/compress — the site creates small AVIF/WebP versions automatically.
