# AI image prompts — ছবি বানানোর প্রম্পট

Use these in Canva (Magic Media / "Generate image"), ChatGPT, Gemini or any image AI.
Save each result into `public/images/real/` with the **exact file name** shown — it replaces the current photo automatically on the next build/deploy.

প্রতিটা প্রম্পট কপি করে AI-তে দিন, ছবিটা ডাউনলোড করে নিচের নাম দিয়ে `public/images/real/` ফোল্ডারে রাখুন।

**Always check before using:** steering wheel on the RIGHT side of the car, car on the LEFT side of the road, no strange hands/faces, no random text or fake number plates.
**ব্যবহারের আগে যাচাই করুন:** স্টিয়ারিং গাড়ির ডান দিকে, গাড়ি রাস্তার বাম পাশে, হাত-মুখ স্বাভাবিক, কোনো উল্টাপাল্টা লেখা নেই।

Common ending to add to every prompt:
> Realistic photograph, natural soft light, Bangladesh, right-hand-drive car, traffic keeps left, no text, no watermark, 16:9.
